# Changelog

User-visible changes only. Release notes are cut from this file, one section per release.

## 0.1.0 — 2026-08-19

First public release.

- Save an "eGPU" profile and an "Internal" profile for each registered game, and apply either one to every game at once.
- Automatic detection of Proton games, per-game apply and save, and automatic backups with restore (up to 10 per game).
- Verified on SteamOS. Bazzite is not verified. Proton games only.
